# Fashion Usage Classification

An AI/ML assignment exploring fashion product colours and attributes.

## Dataset
Fashion Product Images (Small) from Kaggle, using styles.csv.

## Work Completed
- Explored rows, columns, and product categories
- Checked missing values and duplicate rows
- Examined colour and usage distributions

## Planned Machine Learning Task
Supervised multiclass classification to predict product usage,
such as Casual, Formal, Sports, or Ethnic.

Proposed models: Random Forest and Logistic Regression.
Model training and evaluation are not yet completed.
